ABLATION RUN SETTINGS — abl_no_vflw (row 8)  [leave-one-out]
================================================================
Study    : VnPollenBee ablation (abiliation/study_specifications.md)
Purpose  : Full model MINUS VFL-w. Leave-one-out row — isolates the
           classification bundle's (weighted Varifocal loss) MARGINAL
           contribution on top of CBAM + BoT + SAF-SIoU. Leave-one-in
           (row 4, abl_vflw) showed VFL-w alone was +0.009 AP over
           baseline (below the noise floor), recall-oriented (R
           0.857->0.899); this row asks the harder question the
           leave-one-in cannot: does VFL-w still add anything once
           CBAM/BoT/SAF are already present? If AP is unchanged vs
           abl_full, VFL-w is redundant in the full stack and the final
           model can revert to stock BCE; if AP RISES, the weighted VFL
           was contributing to the full-model regression.
Branch   : run/abl_no_vflw  (branched from run/abl_saf-chain; args.yaml
           reset to run/abl_full then the one bundle reverted)

COMPONENTS (protocol §2/§3) — VFL-w OFF, other three ON
----------------------------------------------------------------
CBAM      : ON    (POLLENBEES_ATTN=cbam_botnet — CBAM on P3/P4/P5 maps)
BoT       : ON    (POLLENBEES_ATTN=cbam_botnet — P5 C2f -> BoTNet MHSA)
SAF-SIoU  : ON    (box_loss_type: saf_siou)
VFL-w     : OFF   (cls_loss_type: bce, cls_pos_weight: [1.0, 1.0] —
                   stock unweighted BCE, exactly as abl_baseline row 0)

Config delta vs abl_full (row 9) — EXACTLY ONE factor (the §2 cls bundle):
  env var : POLLENBEES_ATTN cbam_botnet   (UNCHANGED — CBAM+BoT stay on)
  utils/args.yaml : cls_loss_type vfl -> bce
                    AND cls_pos_weight [1.0, 2.0] -> [1.0, 1.0]
Both flips are the SINGLE classification bundle (§2: weighted VFL vs
stock BCE ablated together), so this is a valid one-factor leave-one-out.
IMPORTANT: cls_pos_weight is applied to BCE as pos_weight too (util.py
L765-768) — flipping only the loss type would leave a WEIGHTED BCE, which
is NOT stock BCE. The weight MUST be reset to [1.0, 1.0]. Box stays
saf_siou (SAF-SIoU on).

Architecture note: like abl_no_saf (row 7), this is a LOSS-only change —
the network is byte-identical to abl_full (CBAM+BoT, cbam_botnet). Same
network as abl_no_saf; the two rows differ only in WHICH loss component
is dropped (row 7 drops SAF-SIoU, row 8 drops VFL-w). There is no
leave-one-in loss-only sibling to match against; the comparison that
matters is directly against abl_full.
